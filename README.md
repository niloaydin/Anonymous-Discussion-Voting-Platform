# 🗳️ Anonymous Discussion & Voting Platform

## 🧩 Overview

The **Anonymous Discussion & Voting Platform** is built to provide a safe, censorship-free space for individuals to discuss ideological or sensitive topics without revealing their identities. Users can anonymously start discussions, define specific voter groups, and later analyze voting outcomes across those groups. This structure encourages free expression while supporting detailed insights into public opinion.

---

## 🛠️ Technology Stack

- **Frontend**: React + Redux  
- **Backend**: Node.js + Express  
- **Database**: MongoDB with Mongoose  
- **Real-Time**: WebSocket  
- **Containerization**: Docker
